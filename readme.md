# Portfolio - Jocelyn ZARROUK

Ce projet est mon **portfolio personnel**, développé pour présenter mon parcours, mes compétences et mes projets.  
Il regroupe à la fois le **frontend (client)** en React et le **backend (server)** en Node.js/Express.

---

## 🚀 Stack technique

- **Frontend (client)** : React, React Router, SCSS
- **Backend (server)** : Node.js, Express, MongoDB Atlas
- **Déploiement** : Vercel (frontend) + Render (backend)

---

## 🎨 Design System

- **Couleur primaire** : `#30464A` (Bleu-vert profond)
- **Couleur légère** : `#FFFFFF` (Blanc pur)
- **Couleur d’accent** : `#F09F81` (Corail doux)

Ces couleurs assurent une cohérence visuelle et une expérience utilisateur moderne, alliant sobriété et dynamisme.

## ⚡ Installation

### 1. Cloner le projet

```bash
git clone https://github.com/ton-compte/portfolio.git
cd portfolio
```

### 2. Installer et lancer le frontend (client)

```bash
cd client
npm install
npm start
```

### 3. Installer et lancer le backend (server)

```bash
cd server
npm install
npm run dev
```

⚠️ Le backend nécessite une connexion à MongoDB Atlas. Pensez à configurer vos variables d’environnement (.env) avec l’URI MongoDB et la clé JWT.
